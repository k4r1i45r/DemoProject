# RaceDay – Event Management System

## System Description
RaceDay is a full-stack web application for the South African road running, walking, and cycling community. Organisers can create and manage events, categories, and results. Participants can browse events, enrol, and track their performance.

## Roles
- **Organiser**: Create, edit, delete events; manage categories; capture results; view all enrolments.
- **Participant**: Register, browse events, enrol in categories, view own enrolments and results.
